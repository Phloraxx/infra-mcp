# Infra identity assets

The logo was created with the built-in image-generation tool for this project.
The PNG, ICO and touch-icon files are production-sized exports of the same mark.

Prompt: Create one original bold geometric monogram inspired by a capital I and an
architectural portal: two solid horizontal caps connected by a central vertical
spine, with precise negative-space cuts suggesting connected computers. Graphite
black on a transparent background, a strong silhouette readable at favicon size,
centered square composition. No wordmark, background tile, mockup or extra symbols.

`logo.png` is the transparent 256 px sidebar/sign-in mark. `favicon.png` is a 64 px
export on a light background; `favicon.ico` contains 16/32/48 px PNG entries;
`apple-touch-icon.png` is the 180 px touch icon. Dark-mode logo display uses CSS
inversion. No external image host or CDN is required.
